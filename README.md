# ozgekuzhan.com

Hi, I'm Ozge 👋

This is the code behind my little corner of the internet: [ozgekuzhan.com](https://www.ozgekuzhan.com).

I'm a full stack developer in Amsterdam, originally from Istanbul. Before I wrote code, I built products. I co-founded a B2B SaaS company, sat in a lot of meetings with customers, wrote a lot of user stories, and spent a lot of time asking developers "is this possible?" At some point I decided I wanted to be the one answering that question. So I went to Le Wagon in Amsterdam, and I haven't stopped building since.

This site is where I keep the things I'm proud of: client work, team projects, and the story of how a product person ended up loving the terminal.

## What's inside

No frameworks, no build step. Just the three things every website starts with:

- `index.html`: all the content, from the intro to the contact section
- `style.css`: the layout, including the mobile version (most people will see this on a phone, so that one matters)
- `script.js`: the small extras, like the image gallery with keyboard navigation and the scroll-to-top button
- `img/`: project screenshots, plus a screen recording of the Shadewell website
- `ozgekuzhanResume.pdf`: my CV, behind the "Resume" button

I kept it simple on purpose. A portfolio should load fast, be easy to read, and get out of the way of the work it shows.

## Run it locally

Clone the repo and open `index.html` in your browser. That's it.

If you want the page to reload while you edit, the VS Code Live Server extension works nicely (this project uses port 5501).

```bash
git clone https://github.com/ozgekuzhan/ozgekuzhan.com.git
cd ozgekuzhan.com
open index.html
```
